Intro to HTML

HTML is a useful language (though not considered a programming language but a markup language instead) which allows users to easily format webpages in the form of a document.

It is based on the document object model (DOM), which provides a common tree-like structure that all pages should follow, and computer scientists love using trees as they can be tested.

A good, well-formatted HTML document must consist of a doctype that explicitly states the version of HTML that you will be using. It should be noted that the <DOCTYPE> declaration is not an HTML tag but instead is information for the browser about what document type it will be dealing with. It must consist of a head that handles the metadata and a body which deals with displayable content

The body naturally makes up the majority of your page, and it is thus essential to write well-formatted (tree-like) code. Although most of the content in the body is displayed by the browser, there might be some metadata too

HTML tags

HTML tags are used to denote various HTML elements. Tags have a beginning and an end. Some tags have attributes like src and href. One of the most important attributes of an element how they are displayed. The two most common HTML elements are block (which can take width and height) and inline (cannot take width and height). A newline is inserted before and after, e.g. it “Takes up” whole width. As for inline, it only uses as much space as needed to contain the element.

There are many different tags in HTML such as the headings (block). It starts from <h1> and goes all the way up to <h6>. Heading tags have syntax and semantics unlike paragraphs (which are blocks) and should only contain inline elements.

The final type of tag is the <div> tag, which is any generic HTML section that is regarded to be bigger than a paragraph.
